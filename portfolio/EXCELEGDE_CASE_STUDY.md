# Excelegde — Case Study

Project: Excelegde
Role: Analyst / Developer (example)

1. Problem statement
Manual spreadsheet workflows often lead to errors, duplicated effort, and slow reporting cycles. Teams need standardised templates, automation, and connectors to source systems.

2. Scope
- Data cleansing templates, automation macros, connectors to databases and APIs, standard reporting templates.

3. Approach
- Review existing spreadsheets and processes.
- Define canonical templates and data validation rules.
- Build python-based automation scripts and Excel add-ins for common tasks.
- Provide documentation and training for end-users.

4. Technologies (example)
- Python, Pandas, openpyxl
- Excel Add-ins (VBA / Office.js)
- CI for automation scripts
